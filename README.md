# MATCH LAB

Find your match. Testes que cruzam seu corpo, nível e estilo com a ficha técnica do equipamento e explicam o porquê de cada escolha.

- **Racket Match** · raquete de tênis · `apps/racket/`
- **Board Match** · prancha de surf · `apps/board/`
- **Tenis Match** · tênis de corrida · `apps/tenis/`

Mais 45 guias em `content/`, lidos pela home (`index.html`).

Site estático: abra `index.html` com um servidor local (`python3 -m http.server`) ou publique a raiz no GitHub Pages ou na Vercel.
